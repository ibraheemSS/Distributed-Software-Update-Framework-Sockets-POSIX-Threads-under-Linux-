# 🔄 Distributed Software Update Framework

<img width="1675" height="555" alt="image" src="https://github.com/user-attachments/assets/3c186f99-cf93-4827-8418-972702b6db7d" />

A client-server software update system developed in C for Linux. The project simulates how multiple clients securely connect to a central update server to check for, download, and verify software updates.

## Features

- Multi-threaded update server
- Multiple client support
- Secure TLS communication
- SHA-256 checksum verification
- Automatic update detection
- Concurrent file transfers
- Real-time server dashboard
- Client authentication
- Logging system

## Technologies

- C
- Linux
- POSIX Threads
- TCP Sockets
- OpenSSL (TLS)
- SHA-256
- OpenGL / FreeGLUT
- Makefile

## Learning Outcomes

This project demonstrates:

- Client-Server Architecture
- Multi-threaded Programming
- TCP Socket Programming
- Secure Communication using TLS
- Cryptographic Hash Verification
- Concurrent Programming
- Linux Systems Programming
